## Tâche : lot X41 — LES FENÊTRES DES SYSTÈMES SERVEUR DU 27/11
Claude a écrit côté serveur des systèmes complets et testés (bancs verts), mais sans interface : le joueur ne peut pas
encore s'en servir. Fais les fenêtres et contrôles client, dans le style du cadre commun (Cadre.lua / X40 si fait).
Le serveur décide de tout : le client envoie seulement les actions listées et affiche les messages `Menu` reçus.
Ne modifie AUCUN fichier serveur (Systemes/*) ; s'il te manque une donnée, ajoute une ligne « Codex → Claude » dans les Passages.

1. MAGIE (`Systemes/Magie`) : action `sorts` → message `kind = "sorts", sorts = {{id, name, icon, ecole, cout, reste}}`.
   Une barre de sorts (touches 1–5 maintenues avec une touche modificatrice, ou une roue ; tactile et manette aussi),
   recharge visible (`reste` en secondes), lancer = action `sort { id, target }` (target = id de l'ennemi visé, comme `hit`).
   Un geste « sort » et un effet visuel par école : pyro (boule de feu orange), cryo (trait bleu pâle + givre), druide
   (feuilles vertes en spirale), aero (anneau de vent), geo (peau de pierre grise autour du perso).
2. ROYAUMES (`Systemes/Politique`) : le message `kind = "conseil"` porte `royaume = { nom, suzerain, vassaux, choix, tribut }`.
   Dans la fenêtre du conseil : bloc « Royaume » ; pour le maire (`isMaire`), liste « Prêter allégeance à… » → action
   `pol_allegeance { v = village, to = clé }` et bouton « Rompre l'allégeance » → `pol_allegeance { v = village }`.
3. CONTRATS (`Systemes/Contrats`, mêmes données que /commande) : onglet « Commandes » (tableau du village ou poste) :
   action `contrats` → `kind = "contrats", contrats = {{id, name, uid, item, label, icon, n, prix, reste}}` ; « Publier »
   (objet du sac + quantité + prix) → `contrat_publier { item, n, prix }` ; « Livrer » → `contrat_livrer { id }` ;
   sur ses commandes « Retirer » → `contrat_retirer { id }`.
4. GAZETTE (`Systemes/Gazette`) : onglet « Gazette » au tableau du village : action `gazette` → `kind = "gazette",
   articles = {{id, uid, auteur, titre, texte, jour, village}}` ; « Écrire » (titre ≤ 60, texte ≤ 600) → `gazette_ecrire
   { titre, texte }` ; sur ses articles « Retirer » → `gazette_retirer { id }`. Mise en page de journal ancien.
5. RECORDS ET SUCCÈS SECRETS (`Systemes/Social`) : action `records` (au village) → `kind = "records", records = {{stat,
   label, name, value}}` : un « registre des records » (taverne). Dans la fiche des succès, `secret = true` + nom « ??? ».
6. MARIAGES (`Systemes/Mariages`) : dans le menu d'un joueur ciblé (comme l'invitation de groupe [U]) : « Offrir une bague »
   → `mariage_demande { target = UserId }` ; message reçu `kind = "mariage_demande", from` avec « Oui » → `mariage_oui` ;
   « Divorcer » dans la fiche [P] → `divorce`. Afficher le conjoint (`conjoint = { name, day }`) dans la fiche.
7. CHEFS-D'ŒUVRE (`Systemes/Oeuvres`) : un onglet de la fiche [P] ou du journal : action `oeuvres` → `kind = "oeuvres",
   oeuvres = {{id, voie, name, skill, level, title, have, total, done, needs, got}}` ; barre d'avancée, matières
   manquantes, bouton « Apporter » → `oeuvre { id }` (au village).
8. MODÈLES manquants (ConstruireModeles + Catalogue) : « Scierie » (`sawmill`, aujourd'hui modèle « Etabli » : lame
   circulaire, chevalet, tas de planches) ; changer son `place` dans Equilibre est le couloir de Claude → ajoute un passage.

Vérifie chaque fenêtre au clavier, à la souris, au doigt et à la manette. Capture avant/après si tu peux (sinon Claude
capture). Pas de texte au-dessus des PNJ. Ne pas regrossir le HUD (règle 11).
