# X32 · Armes et équipement portés

Le rendu partagé habille l’avatar et renouvelle les miniatures du sac. En jeu, le signal `Geste` place l’arme équipée dans la main pendant l’animation, puis la remet à son attache de repos. Les outils de la barre gardent leur `Handle`, leur `Grip` et leurs identifiants. La finition ajoute six pièces soudées au manche et à la tête.

La fiche [P] affiche la spécialisation et son passif, le type d’armure, puis Critique, Hâte et Maîtrise avec leur effet chiffré. Les encarts d’objet affichent les affixes en couleur, la durabilité en barre et les pièces brisées en gris. Les objets plus anciens s’affichent avec les champs qu’ils possèdent. Le nom d’un affixe ne change pas la forme du modèle.

## Reconstruction dans Studio Édition

Démarrer `python tools/sync.py` à la racine. Dans la barre de commande de Studio, synchroniser les sources X32 après leur vérification par `loadstring`.

```lua
local h = game:GetService("HttpService")
local bridge = "http://127.0.0.1:34873/"
local paths = {
    "ReplicatedStorage.Shared.Gear",
    "ReplicatedStorage.Shared.GearDesign",
    "ReplicatedStorage.Shared.GearVisuals",
    "ServerScriptService.Systemes.Avatar",
    "ServerScriptService.Systemes.Tools",
    "ServerStorage.OutilsDev.ConstruireModelesMiniatures",
    "ServerStorage.OutilsDev.ConstruireModelesOutils",
    "StarterPlayer.StarterPlayerScripts.Hud",
    "StarterPlayer.StarterPlayerScripts.Interface",
}
local updates = {}
for _, path in paths do
    local object = game
    for _, name in string.split(path, ".") do object = assert(object:FindFirstChild(name), path) end
    local source = h:GetAsync(bridge .. "file?p=" .. h:UrlEncode(path))
    assert(loadstring(source, "=" .. path))
    table.insert(updates, {object, source})
end
for _, update in updates do update[1].Source = update[2] end
```

Reconstruire les outils de `ServerStorage.Outils` en Édition.

```lua
local ss = game:GetService("ServerStorage")
local shared = game:GetService("ReplicatedStorage").Shared:Clone()
shared.Parent = ss
local config = require(shared.Config)
local source = ss.OutilsDev.ConstruireModelesOutils.Source
local models = assert(loadstring(source, "=ConstruireModelesOutils"))()
models.harpon(ss.Outils)
models.equipements(ss.Outils, config)
shared:Destroy()
for _, tool in ss.Outils:GetChildren() do
    if not tool:GetAttribute("FinitionX32") then continue end
    local count = 0
    for _, part in tool:GetDescendants() do if part:IsA("BasePart") then count += 1 end end
    assert(count <= 40, tool.Name)
    print(tool.Name, count)
end
```

Reconstruire `ReplicatedStorage.IconesEquipement` et vérifier les prototypes et torses. Le résultat de chaque banc paraît dans les attributs de `ServerStorage`.

```lua
task.spawn(function()
    local ss, h = game:GetService("ServerStorage"), game:GetService("HttpService")
    local bench = assert(loadstring(h:GetAsync("http://127.0.0.1:34873/banc?f=visuels_equipement"), "=visuels_equipement"))
    for _, mode in {"catalogue", "torses", "x32-prototypes"} do
        local attr = "BancVisuelsEquipement" .. ({catalogue = "Catalogue", torses = "Torses", ["x32-prototypes"] = "Prototypes"})[mode]
        ss:SetAttribute(attr, "en cours")
        local ok, result = pcall(bench, mode)
        ss:SetAttribute(attr, ok and result or "ÉCHEC · " .. tostring(result))
        if ok then print(result) else warn(result) end
    end
end)
```
