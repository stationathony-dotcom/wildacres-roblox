# Wild Acres — vérification de l’interface et des visuels

**216 points contrôlés · 125 OK · 23 corrigés · 68 écarts.** Cette reprise ouvre un passage serveur pour les noms de ville accentués. Le bilan couvre les lignes du tableau. Plusieurs lignes peuvent renvoyer au même correctif. Dans les écarts figurent les reprises visuelles, les comparaisons devenues périmées et les validations réservées au jeu.

Relecture sur disque le 21 novembre 2026, branche `mission/wildacres`. Le contrôle initial couvre les cinq documents, les 26 lots X, les règles 1, 9 et 11 d’`AGENTS.md` et les 30 scripts client d’origine. Cette reprise vérifie aussi les nouveaux modules de charte et de groupe. La première colonne donne les références d’origine. Pour les images, la preuve est le fichier et, lorsque possible, la ligne de son index.

**OK** confirme un branchement sur disque ou un constat corroboré par une capture. **Corrigé** signale une modification de cette passe. **Écart** couvre une divergence, un reste à réaliser ou une affirmation que le disque seul ne permet pas de valider. Les chiffres de bancs et les résultats Play datés restent des relevés historiques. Aucun banc Studio ni test Play n’a été relancé pour cette passe.

Le projet Rojo 7.7.0 se construit sur disque et inclut `CharteVille` et `GroupeHud`. L’analyse lexicale initiale des 30 scripts client retrouvait les huit accès hors portée de l’ancienne version du correctif `54069dc` et n’en relevait aucun dans la version alors auditée.

Les noms de fichiers client désignent `src/StarterPlayer/StarterPlayerScripts/`, ceux de `Gear`, `GearDesign`, `Catalogue`, `Config`, `Eclairage`, `HerbeHaute` et `Equilibre` désignent `src/ReplicatedStorage/Shared/`. Les scripts serveur nommés désignent `src/ServerScriptService/Systemes/`. Les constructeurs `ConstruireModeles*` sont dans `src/ServerStorage/OutilsDev/`. Les bancs sont dans `tools/bancs/`.
